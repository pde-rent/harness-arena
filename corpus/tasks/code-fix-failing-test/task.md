# Make the ledger test suite green

This repository is a double-entry accounting ledger library. Its test suite is currently failing.

Run the tests, find the cause, and fix it so that the whole suite passes.

Constraints:

- Fix the production code. Do not change, delete, skip or weaken any existing test.
- Do not change the public API: the exported names and their signatures must stay as they are.
- The fix must be a real fix, not a special case for the values that happen to appear in the tests.
